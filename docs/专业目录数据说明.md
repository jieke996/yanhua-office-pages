# 专业目录数据说明

本文件说明 `tools/major-query` 专业类别查询系统的数据来源、口径与维护方式。
**`majors.json` 是产物，请勿手工编辑**；如需更新，改 `build_majors.py` 或替换 `_src/` 下的官方原件后重新生成。


## 三、几个容易踩的坑（已处理）

1. **本科 PDF 是分栏排版**，代码列与名称列在同一视觉行但 y 坐标差 1~2pt，按 y 精确分组会漏行。脚本用 5pt 容差聚行后再按 x 分列。
2. **外语类专业代码有 7 位**（`0502100T` 语言学 等 8 个），只匹配 6 位会漏掉。
3. **职业教育专业代码带 K/T 后缀**（如 `520101K` 临床医学），需允许字母后缀。
4. **临床医学/口腔医学/药学 三个专硕类别没单列**，写在对应一级学科的括注里（「1002 临床医学（同时设专业学位类别，代码为1051）」），脚本单独抽取，故专硕类别为 61 + 3 = 64。
5. **艺术、工程两个大口径专硕在 2022 版被拆分**，2021 版的领域代码需映射到新类别（`RESTRUCTURED` 表），否则「美术」会挂错父级。

## 四、旧专业名别名（alias）

旧版数据库（2011 研究生 / 2024 本科 / 2015 专科）里存在、现行目录已改名的专业，由脚本按字符串相似度自动挂成 `alias`，
仅在「相似度 ≥ 0.6 且最佳匹配唯一」时才挂，避免张冠李戴。效果示例：

- 云计算技术与应用 → 云计算技术应用（510206）
- 人工智能技术服务 → 人工智能技术应用（510209）
- 中草药栽培技术 → 中草药栽培与加工技术（410108）

存疑映射写入 `_alias_review.json` 供人工复核；未自动映射的旧名不会强行挂接（宁可查不到，不给错答案）。
另有人工确认的常用别名表 `SPECIAL_ALIAS`（如 书法 → 1356 美术与书法、MBA → 1251 工商管理）。

## 五、已知缺口

- **职业教育 2024/2025/2026 三轮增补未并入**：教育部自 2021 年起每年增补，累计增补 169 个专业（专科约 60 个、职业本科约 58 个）。这些是近两年新设专业，目前极少出现在事业单位岗位要求中，故暂缓；补齐方式是把三轮增补清单另存进 `_src/` 并在脚本中追加合并。
- 军事学门类部分专业未公开收录。
- 本科 2026 版另增「交叉学科」门类（15 个专业），该门类不设专业类，脚本已合成「交叉学科类」承载，页面「专业类」列显示为 `—`。

## 六、维护流程

```bash
cd tools/major-query
python3 build_majors.py --report   # 只核对条数，不写文件
python3 build_majors.py            # 重新生成 majors.json
node test_majors.js                # 36 项回归断言，必须全绿
```

教育部每年 3~4 月更新本科目录、7 月增补职教专业，建议每年 4 月与 9 月各跑一次。
